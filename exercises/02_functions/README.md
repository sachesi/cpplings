# Functions

Functions are declared with their return type first, then the name and the
parameters, each with its own type: `int add(int a, int b)`. A function that
returns nothing has the return type `void`.

The compiler reads a file from top to bottom, so a function must be declared
before it is called. A declaration without a body (a "prototype") is enough;
the definition can come later.
