# Loops

A `while` loop repeats its body as long as a condition is true. A `for` loop
bundles the three parts of a counting loop in one line: the initialization, the
condition and the step, as in `for (int i = 0; i < 10; ++i)`. A `do`-`while`
loop checks its condition after the body, so the body runs at least once.

`break` leaves the loop immediately, and `continue` skips the rest of the body
and goes on with the next iteration.

Loops that count are a classic place for off-by-one errors. Check the first and
the last iteration: does the loop start and stop where you expect?
