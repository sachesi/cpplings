# Intro

C++ is a compiled language: before a program can run, a compiler such as GCC or
Clang translates the source code into machine code. cpplings compiles every
exercise with warnings enabled, runs it and shows you the output.

The compiler's messages can be long, but the first error is usually the one that
matters. Read it carefully: it names the file, the line and what went wrong, and
it often suggests a fix.
